# 동현콥 v0.1

누르면 오르고 떼면 내려가는 고전 플래시 헬리콥터 게임을 **원본 파일 그대로** 띄우고, 헬리콥터의 속도만 동현랭으로 정하는 원버튼 비행 실험실이다.
동현 시리즈의 여섯 번째 작은 실험이다.

바로 하기: https://raspberry-kim.github.io/donghyun-cop/

- 조작: 데스크톱은 마우스 왼쪽 버튼, 태블릿·휴대전화는 게임 화면 터치 하나뿐이다. 누르고 있으면 오르고, 떼면 내려간다.
- 소리: 원본에 든 효과음 3개가 그대로 난다(첫 누르기 뒤부터).
- 원본: `swf/helicopter-game.swf` (44,807바이트, SHA-256 `ed5fbfd0ca488edc6d94c275c609d894d43d87e72922f76332333034cca7e071`). 한 바이트도 고치지 않았고, 페이지가 열릴 때마다 해시를 다시 확인한 뒤에만 띄운다.

## 동현콥 속도 규약

동현랭 코드가 출력한 **정수 하나**가 속도(%)다.

| 출력 | 뜻 |
|---|---|
| 100 | 원본 그대로(초당 30프레임) |
| 50–200 | 쓸 수 있는 범위. 초당 프레임 = 30 × 속도 ÷ 100 |
| 출력 없음 | 100으로 난다 |
| 정수 둘 이상, 범위 밖 | 이륙하지 않고 오류를 알린다 |

예제는 `01 · 원본 그대로` 하나다(기본값 100).

```
나는 동현이냐?
ㅋㅋ 속도 100 · 원본 그대로 · 50부터 200까지
뿡뿡 도오오오오오오오오오옹 도오오오오오오오오오옹~뿡뿡뿡
동현이구나
```

## 원본을 고치지 않고 띄우는 방법

`src/wrapper.js`가 400×300 크기의 작은 바깥 SWF를 그때그때 만든다. 바깥 SWF는 해시를 확인한 원본 바이트를 `_level1`로 불러오고, 초당 프레임 수로 속도를 정한다.
원본은 첫머리에서 Flash 5 명령으로 'start' 프레임(5번)에 넘어가고, 옛 플레이어에서만 '플러그인을 설치하라'는 4번 프레임에 멈춘다. Ruffle에서는 이 넘김이 4번 프레임을 그린 뒤에 일어나거나 일어나지 않아, 안내 화면이 남거나 멈춘다. 바깥 SWF는 원본이 4번 프레임을 거치면 3번으로 한 번 되감았다가 5번으로 넘겨 준다.
